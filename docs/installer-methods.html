Haltdos Installation Methods

Haltdos · Build & Release  ·  Last updated April 2025  ·  8 min read

There are three separate ways to install Haltdos depending on your environment and requirements. Each method is independent — choose the one that fits your setup.

🐧 Rocky Linux / RHEL / CentOS
Method How it works Use when
Method 1 — wget Download Downloads the pre-built binary directly from the Haltdos server Quickest — no build required
Method 2 — Go Installer Runs the installer binary with the update server URL Standard — after building or downloading
Method 3 — Java Installer Installs Java first, then runs the installer in standalone mode Java env — when Java runtime is required

Installation Methods

Method 1

Download via wget

Download the pre-built installer binary directly from the Haltdos internal server

Use this method to download the latest pre-compiled haltdos-installer binary directly onto the target machine. No build tools or Go environment required.

1
Run the wget command
bash — root@server
$ wget https://haltdos-internal.haltdos.com/resources/installer/v8/haltdos-installer Resolving haltdos-internal.haltdos.com... Connecting to haltdos-internal.haltdos.com... HTTP request sent, awaiting response... 200 OK Saving to: 'haltdos-installer' haltdos-installer 100%[=============================>] ~16M received
2
Make the binary executable
bash — root@server
$ chmod +x haltdos-installer

💡 After downloading, the binary is ready to use. You can now proceed with Method 2 (Go installer) to run it and install Haltdos.

⚠️ This URL points to the internal Haltdos server. Make sure your machine has network access to haltdos-internal.haltdos.com before running this command.

Method 2

Go Installer

Run the haltdos-installer binary directly to install Haltdos

Use this after you have obtained the haltdos-installer binary (either via Method 1 wget download or by building from source). This runs the installer and connects to the Haltdos update server.

1
Run the installer
bash — root@server
$ ./haltdos-installer install -m https://update.haltdos.com

Here is what each part of the command means:

Part Value Description
./haltdos-installer — Executes the installer binary from the current directory
install — The install subcommand — triggers the full installation process
-m https://update.haltdos.com Mirror / update server URL — where the installer fetches packages from

⚠️ The target machine must have outbound internet access to https://update.haltdos.com for the installer to fetch the required packages during installation.

Method 3

Java Installer (Standalone)

Install Java first, then run the Haltdos installer in standalone mode

Use this method when your environment requires a Java runtime. This is a two-step process — first install Java 21, then run the Haltdos installer in STANDALONE mode with your license key and target IP.

1
Install Java 21 (OpenJDK)

Use dnf to install the Java 21 OpenJDK runtime on Rocky Linux / RHEL / CentOS:

bash — root@server
$ sudo dnf install java-21-openjdk -y Last metadata expiration check: ... Dependencies resolved. Installing: java-21-openjdk ... Complete!

💡 The -y flag automatically confirms all prompts during installation so you don't have to type "yes" manually.

2
Run the Haltdos installer in Standalone mode

Once Java is installed, run the Haltdos installer with the following flags:

bash — root@server
$ ./haltdos-installer install -v -t STANDALONE -m https://update.haltdos.com -l G9BWD2YQNI --ip 172.16.0.65

Here is what each flag means:

Flag Value Description
install — Triggers the installation process
-v — Verbose mode — prints detailed output during installation
-t STANDALONE Installation type — STANDALONE installs Haltdos as a single self-contained node
-m https://update.haltdos.com Mirror / update server URL — where packages are fetched from
-l G9BWD2YQNI License key — your unique Haltdos activation license
--ip 172.16.0.65 The IP address of the machine being installed on

⚠️ Replace G9BWD2YQNI with your actual license key and 172.16.0.65 with the real IP address of your target machine before running this command.

✅ Done! Once the command completes, Haltdos is installed in standalone mode and will be accessible at the IP address you provided.
