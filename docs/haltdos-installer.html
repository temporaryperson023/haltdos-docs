Obtaining the Haltdos Installer

Haltdos · Build & Release  ·  Last updated April 2025  ·  5 min read

This guide documents how to build the haltdos-installer binary from source using the platform-exp-aux-setup repository. The installer is located inside the experimental project group and is built using a simple shell script.

🗂 ~/git › experimental › platform-exp-aux-setup

Prerequisites

Before you begin, make sure the following are in place:

  • The haltdos hd-tools repository is cloned and all dependent projects are available under ~/git/
  • You have run the initial devops checkout and build (see the Binary Components Upload doc)
  • Go is installed on your machine (required to compile the installer binary)
  • You have execute permissions on build.sh

Repository Location

The installer lives inside the experimental project group, not the main api or aux groups. Here is the full layout of the ~/git/ directory for reference:

~/git/   ├── api/   ├── apps/   ├── aux/   ├── common/   ├── community/   ├── experimental/  ← you are going here   │   ├── platform-exp-aux-cli/   │   ├── platform-exp-aux-setup/  ← installer lives here   │   └── platform-exp-gui-admin/   ├── gui/   ├── hd-tool-devops/   ├── manager/   ├── pro/   ├── rules/   ├── ticket/   ├── tools/   └── wiki/

Step-by-Step Guide

1

Navigate to the git directory

Start from your home directory and move into the git/ folder where all Haltdos repositories are cloned.

bash — haltdos@haltdos-Kartik
haltdos@haltdos-Kartik:~$ cd git haltdos@haltdos-Kartik:~/git$ ls api   aux     community     gui             manager  rules   tools apps  common  experimental  hd-tool-devops  pro      ticket  wiki

You should see the experimental/ directory listed alongside all the other project groups.

2

Navigate into the experimental directory

Change into the experimental/ directory and verify the repositories inside it.

bash — haltdos@haltdos-Kartik
haltdos@haltdos-Kartik:~/git$ cd experimental/ haltdos@haltdos-Kartik:~/git/experimental$ ls platform-exp-aux-cli  platform-exp-aux-setup  platform-exp-gui-admin

You will see three repositories. The one you need is platform-exp-aux-setup.

3

Navigate into the setup repository

Change into platform-exp-aux-setup/ and check its contents before building.

bash — haltdos@haltdos-Kartik
haltdos@haltdos-Kartik:~/git/experimental$ cd platform-exp-aux-setup/ haltdos@haltdos-Kartik:~/git/experimental/platform-exp-aux-setup$ ls build.sh         go.mod  haltdos-installer  scripts dependency.json  go.sum  README.md          src

Here is what each file and folder is:

platform-exp-aux-setup/   ├── build.sh ← the build script you will run   ├── go.mod ← Go module definition   ├── go.sum ← Go dependency checksums   ├── dependency.json ← component dependency manifest   ├── README.md ← basic project readme   ├── haltdos-installer ← the compiled binary (generated after build)   ├── scripts/ ← supporting shell scripts   └── src/ ← Go source code

💡 The haltdos-installer binary may already exist from a previous build. Always run build.sh fresh to get the latest compiled version.

4

Run the build script

Execute build.sh to compile the installer binary. This will download any Go dependencies and produce the final haltdos-installer executable.

bash — haltdos@haltdos-Kartik
haltdos@haltdos-Kartik:~/git/experimental/platform-exp-aux-setup$ ./build.sh

⚠️ The build script produces no output on success — a blank return to the prompt means the build completed successfully. If you see errors, check that Go is installed and your network can reach the Go module proxy.

5

Verify the installer binary was created

Run ls -ltrh to confirm the binary was generated and check its size and timestamp. A freshly built installer should be around 16 MB.

bash — haltdos@haltdos-Kartik
haltdos@haltdos-Kartik:~/git/experimental/platform-exp-aux-setup$ ls -ltrh total 16M -rw-rw-r-- 1 haltdos haltdos 11 Feb 4 17:20 README.md -rwxrwxr-x 1 haltdos haltdos 530 Feb 4 17:20 build.sh drwxrwxr-x 14 haltdos haltdos 4.0K Feb 4 17:40 src -rw-rw-r-- 1 haltdos haltdos 11K Apr 15 15:50 go.sum -rw-rw-r-- 1 haltdos haltdos 1.4K Apr 15 15:50 go.mod -rw-rw-r-- 1 haltdos haltdos 25K Apr 15 15:50 dependency.json drwxrwxr-x 2 haltdos haltdos 4.0K Apr 15 15:50 scripts -rwxrwxr-x 1 haltdos haltdos 16M Apr 29 11:06 haltdos-installer

✅ Success! The haltdos-installer binary is present, is 16M in size, has execute permissions (-rwxrwxr-x), and its timestamp matches today's build time. Your installer is ready to use.

Key things to verify in the output:

  • The file is listed as haltdos-installer at the bottom (most recently modified)
  • Permissions begin with -rwxrwxr-x — the x confirms it is executable
  • Size shows 16M — a significantly smaller file may indicate an incomplete build
  • The timestamp matches when you ran ./build.sh
