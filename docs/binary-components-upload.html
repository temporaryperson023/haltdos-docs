Binary Components Upload Steps

ADC Build & Release Documentation  ·  Last updated April 2025  ·  10 min read

Component-wise detailed guide for building and uploading all ADC binary components to the License Manager.

Prerequisites

  1. Clone the haltdos hd-tools repository.
  2. Run the required command to clone all dependent projects.

Initial Setup

Step 1

Navigate to DevOps Directory

cd /git/hd-tool-devops
Step 2

Checkout & Build All Projects

./devops checkout && ./devops build
  • Switches all repositories to release-candidate
  • Pulls latest code for all projects

1. CLI

📁 /git/aux/platform-exp-aux-cli/
Step 1

Navigate

cd /git/aux/platform-exp-aux-cli/
Step 2

Check Latest Version

Go to License Manager → Binary → CLI

Step 3

Build

./build.sh -p <latest_version>
Step 4

Generate Hash

sha512sum <generated_tar_file>
Step 5

Upload

Go to License Manager → Component → Binary → CLI → Add Version

  • Description
  • SHA512 hash
  • Upload tar file
  • Click Confirm

3. Offloader (Two Types)

🔹 A. Ubuntu Offloader (Local Machine)

📁 /git/api/platform-api-console/
cd /git/api/platform-api-console/

Go to License Manager → Binary → Offloader

./build.sh -p <latest_version>
sha512sum <generated_tar_file>

Go to License Manager → Component → Binary → Offloader → Add Version, add Description, SHA512 hash, upload tar file, click Confirm.

🔹 B. Rocky (RHEL) Offloader — offloader-rhel

⚠️ Important: Built ONLY on Rocky Linux VM (Office VMs).

Step 1

Clone Repository (on Rocky VM)

git clone <offloader-repo-url>
cd <repo-folder>
Step 2

Switch Branch & Update

git checkout release-candidate
git pull
Step 3

Build

./build.sh -p <latest_version>
Step 4

Transfer to Local Machine

scp <generated_tar_file> <local_user>@<local_ip>:<destination_path>
Step 5

Generate Hash & Upload

sha512sum <generated_tar_file>

Go to License Manager → Component → Binary → Offloader → Add Version

💡 This Rocky build process applies to all RHEL-based components — Offloader, Balancer, Gateway. All follow: Build on Rocky VM → Transfer via SCP → Upload from local system.
