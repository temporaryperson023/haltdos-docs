Binary Components Upload Steps

ADC Build & Release Documentation  ·  Last updated April 2025  ·  10 min read

Prerequisites

  1. Clone the haltdos hd-tools repository.
  2. Run the required command to clone all dependent projects.

Initial Setup

Step 1

Navigate to DevOps Directory

cd /git/hd-tool-devops
Step 2

Checkout & Build All Projects

./devops checkout && ./devops build
  • Switches all repositories to release-candidate
  • Pulls latest code for all projects

1. CLI

📁 /git/aux/platform-exp-aux-cli/
Step 1

Navigate

cd /git/aux/platform-exp-aux-cli/
Step 2

Check Latest Version

Go to License Manager → Binary → CLI

Step 3

Build

./build.sh -p <latest_version>
Step 4

Generate Hash

sha512sum <generated_tar_file>
Step 5

Upload

Go to License Manager → Component → Binary → CLI → Add Version

  • Description
  • SHA512 hash
  • Upload tar file
  • Click Confirm

🔹 B. Rocky (RHEL) Offloader — offloader-rhel

⚠️ Important: Built ONLY on Rocky Linux VM (Office VMs). Do NOT build this on your local Ubuntu machine.

Step 1

Login to Rocky VM

SSH into the designated Rocky Linux office VM before proceeding.

Step 2

Clone Repository

git clone <offloader-repo-url>
cd <repo-folder>
Step 3

Switch Branch & Update

git checkout release-candidate
git pull
Step 4

Build

./build.sh -p <latest_version>
Step 5

Transfer Build to Local Machine

scp <generated_tar_file> <local_user>@<local_ip>:<destination_path>
Step 6

Generate Hash (on local machine)

sha512sum <generated_tar_file>
Step 7

Upload

Go to License Manager → Component → Binary → Offloader → Add Version

💡 Note: This Rocky build process applies to all RHEL-based components — Offloader, Balancer, Gateway, and any similar builds. All follow the same pattern: build on Rocky VM → transfer via SCP → upload from local system.
