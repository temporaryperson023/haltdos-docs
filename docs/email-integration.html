E-Mail Integration

Haltdos · Integrations  ·  Last updated April 2025  ·  5 min read

This page documents the Email Integration configuration under System → Integrations → E-Mail in the Haltdos dashboard. It covers all available fields, their purpose, and recommended values.

🗂 System › Integrations › E-Mail

Basic Settings

Field Value / Type Description
Enable Notifications Enabled Enables notification delivery via Email.
Email Server smtp.gmail.com or smtp-mail.outlook.com Hostname or IP address of the outgoing SMTP server.
Server Port 587 Port used to connect to the email server. Port 587 is standard for TLS/STARTTLS.
Connection Timeout 0 Milliseconds Timeout for establishing a connection. Set to 0 to disable.
Socket Timeout 0 Seconds Timeout for socket-level communication. Set to 0 to disable.

Authentication

Field Value / Type Description
Enable Authentication Enabled Enables credential-based authentication when connecting to the SMTP server.
Email Address your@gmail.com The email address used for authenticating with the SMTP server.
Email Password •••••••••••••• Password for the above email account. Use an App Password if 2FA is enabled on Gmail.
Technical Support Disabled When enabled, sends critical alert notifications to Haltdos technical support.

⚠️ Gmail users: If your account has 2-Factor Authentication enabled, you must generate and use an App Password instead of your regular Gmail password. Regular passwords will be rejected by Google's SMTP server.

Encryption & Protocol Settings

Field Value / Type Description
Encryption Protocol TLS Type of encryption used when connecting to the email server.
DSN Response None Type of Delivery Status Notification response on delivery failure.
DSN Notify None Specifies when to send a DSN notification.
Enable EHLO Enabled Initiates the SMTP connection using the EHLO command for extended features.
Start TLS Enabled Upgrades the connection to SSL/TLS after initial connection. Required for port 587.
Enable 8-bit Mime Disabled Enable only for compatibility with older email servers that require 8-bit MIME encoding.
Enable Partial Email Disabled Allows sending partial emails. Leave disabled unless specifically required.
Enable UserSet Disabled Uses RSET command instead of NOOP while sending email when enabled.
Enable Quit Wait Enabled Gracefully terminates the connection with the email server after sending.

Actions

Two buttons are available at the bottom of the configuration page:

  • Send Test Mail — Sends a test email using the current configuration to verify everything is working correctly before saving.
  • Save Changes — Saves all configuration changes to the system.

💡 Tip: Always click Send Test Mail first to confirm the SMTP connection is working before hitting Save Changes.
